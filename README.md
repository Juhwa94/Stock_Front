센서와 네트워크 기반의 소규모 스마트팜
도시에서 식물을 키우고 싶어도 키우지 못하는 사람들을 위한 소규모 스마트팜 앱개발 프로젝트입니다.

👨‍🏫 프로젝트 소개
사용자는 CCTV를 설치하여 사용자가 영상으로 작물 상태를 확인하고 온도 센서와 습도 센서를 통하여 사용자가 확인할 수 있도록 온도, 습도 정보를 체크합니다. 환기를 위한 창문을 설치하여 원격으로 창문을 자동 제어하며 사용자가 설정하여 물을 줄 수 있는 워터펌프를 설치하여 ON모드로 물을 줄 수 있도록 하는 소규모의 스마트팜입니다.

📌 주요 기능
AWS EC2 인스턴스를 생성하여 퍼블릭 DNS나 IP를 사용하여 사용자가 서비스에 접근
윈도우 운영체제를 사용하여 PuTTY를 사용하여 원격으로 리눅스 서버에 접속
AWS에서 제공하는 RDS 서비스를 이용하여 MySQL 엔진으로 데이터베이스를 생성하고 관리
소켓 통신하여 사용자가 안드로이드를 통해 수동으로 관리하기 버튼을 누르고 워터펌프, 환기팬, LED를 구동
소켓 통신의 요청과 응답을 받기 위해 코틀린의 Queue 클래스를 활용
InetSocketAddress객체를 통해 라즈베리파이의 호스트네임과 포트번호를 넘겨줘 연결
안드로이드와 통신하기 위해 RecvThread로 연결
농장의 온도, 습도, 조도 센서값을 받아오기 위해 SensorThread 클래스를 선언
센서값이 측정되었을 때 적정값에 맞춰지도록 엑츄에이팅 관계를 설정
📂 프로젝트 특징
AWS 기반 클라우드 인프라 구축 : EC2와 RDS를 활용하여 서버 및 데이터베이스 환경을 직접 구축하고 운영한 스마트팜 시스템
IoT 디바이스 원격 제어 기능 구현 : 안드로이드 애플리케이션을 통해 워터펌프, 환기팬, LED를 실시간으로 제어할 수 있는 원격 관리 기능 제공
소켓 통신 기반 실시간 데이터 처리 : Android ↔ Raspberry Pi 간 TCP Socket 통신을 구현하여 센서 데이터 수집 및 제어 명령 전달
환경 데이터 모니터링 시스템 개발 : 온도, 습도, 조도 센서값을 실시간으로 수집하고 사용자에게 제공
자동 제어(Actuating) 기능 구현 : 측정된 센서값을 기준으로 적정 환경을 유지하도록 장치가 자동으로 동작하는 스마트 자동화 시스템 구축
멀티스레드 기반 안정적인 통신 구조 설계 : RecvThread, SensorThread를 활용하여 센서 데이터 수집과 장치 제어를 독립적으로 처리해 시스템 안정성 향상
