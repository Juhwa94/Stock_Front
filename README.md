## 👨‍🏫 프로젝트 소개
> 본 프로젝트는 서점 리테일러의 효율적인 매장 운영을 지원하기 위한 재고·매출 관리 웹 서비스입니다. 매장 인증을 기반으로 상품 재고 관리, 판매 내역 조회, 매출 분석, 발주 관리 기능을 구현하여 리테일러의 업무 편의성을 높였습니다. 데이터 기반의 의사결정을 통해 재고 관리 효율성을 개선하고 안정적인 거래 환경을 제공하는 것을 목표로 개발하였습니다.
## ⏲️ 개발 기간   
> - 2026.7.3(금) ~ 2026.7.29(수)
> - Oracle Database 연동
> - Spring Boot를 통한 ERP관리 서비스 구현
> - React를 통한 UI/UX 업데이트 및 구현
> - CRUD RESTful API 구현
> - Open API 우편번호 주소 연동
  
## 🧑‍🤝‍🧑 개발자 소개 
> - **주용현** : 팀장, 프로젝트 총괄 및 관리자 페이지 CRUD RESTful API 구현
> - **이주화** : UI 설계 및 레이아웃 설계, React 기반 메인 UI/UX 수정 및 보완, Open API 연동
> - **최솔**   : Redis를 활용한 이메일 인증 토큰 저장 및 검증, AOP 적용으로 로그인 로깅 기능 구현
> - **임동혁** : 공지사항 CRUD RESTful API 구현, 동적 쿼리 및 페이징, API 테스트
> - **김진규** : React를 활용한 UI/UX 설계, 동적 쿼리를 사용한 백엔드 로직 작성
> - **허승표** : React를 활용한 UI/UX 설계, 동적 쿼리를 사용한 백엔드 로직 작성
> - **오진석** : 디자인된 평가 폼을 재구성하여 백엔드 연동, MUI X Chart를 사용하여 평점 시각화
> - **최원철** : 데이터 모델링 1:N 관계를 설계하여 댓글 엔티티 설계 및 구현, 동적 쿼리 및 페이징, API 테스트

## 📌 주요 기능

> - 서점 점주(리테일러) 전용 계정 생성 및 매장 정보를 인증하여 역할 기반 권한 관리를 통한 매장별 접근 제어를 활용했습니다.
> - ISBN 연동을 통한 도서 등록, 수정, 삭제 및 도서 정보 자동 채우기를 통해 수량 변화, 위치 추적, 재고 부족 알림을 포함한 실시간 재고를 추적하는 시스템을 개발하였습니다.
> - 출판사 대상 도서 입고 및 발주 요청서를 작성하거나 수발신할 수 있으며, 적정재고 유지를 계산하도록 기능을 개발하였습니다.
> - 일간·월간·분기별 매출 흐름 비주얼 분석 차트를 만들어 판매 통계 및 정산 데이터를 알 수 있도록 하였습니다.
> - 점주 간 재고 유통, 운영 노하우 공유를 위한 커뮤니티 게시판을 만들고 도서 수급 및 재고에 대해서 문의할 수 있는 기능을 구현하였습니다.



## 📂 프로젝트 특징
> 1. 비즈니스 로직(Model), 사용자 인터페이스(View), 흐름 제어(Controller)의 명확한 역할 분리로 MVC 패턴 기반의 높은 확장성을 구현했습니다.
> 2. 단순 상품 판매가 아닌, 도서 유통 구조(ISBN, 출판사, 발주 체계)를 깊이 이해하고 반영한 리테일러 전용 솔루션을 구현했습니다.
> 3. 입고 ➔ 재고 ➔ 판매 ➔ 발주 ➔ 정산으로 이어지는 유통 및 관리 전 과정을 하나의 플랫폼에서 처리하여 운영 라이프사이클의 원스톱을 통합하였습니다.
> 4. 직관적인 데이터 시각화를 통해 재고 과다/부족 리스크를 줄이고 효율적인 매장 운영 판단 지원하여 데이터 기반의 인사이트를 구축했습니다.
> 5. 복잡한 수치와 재고 목록을 단번에 파악할 수 있는 사용자 친화적 대시보드 및 워크플로우 구성하여 직관적인 UI/UX를 구현했습니다.
